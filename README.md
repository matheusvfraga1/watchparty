# Watch Party — assista junto com amigos

Salas abertas/privadas (com senha opcional), chat ao vivo, reações e vídeo sincronizado no PC e celular.

Fontes: YouTube · Google Drive (público) · link direto (.mp4/.webm/.m3u8) · arquivo local (transmitido ao vivo do seu PC) · Netflix/Prime/Disney+/Max etc. (compartilhando a aba do Chrome com áudio).

## Rodar
```
npm install
npm start   # http://localhost:3000
```

## Publicar (Render, grátis)
New → Web Service → este repositório → Build: `npm install` · Start: `npm start`.
